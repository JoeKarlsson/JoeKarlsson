# Design decisions

Joe's standing verdicts for this profile README, dated. Read before any change; add each new verdict when Joe gives it. The site's own verdicts (joekarlsson.com `DECISIONS.md`) apply here too.

- 2026-11-12: Layout is "Option A": a poster banner (JOE KARLSSON + "I build weird things and show my work"), a two-line intro, latest posts as the site's taped pink thumbnails, then the link badges.
- 2026-11-12: No employer or job title anywhere in the README.
- 2026-11-12: No project list and no "recently shipped" block: the pinned repos and the contribution graph sit right below the README.
- 2026-11-12: No snake animation (the contribution graph is already on the page).
- 2026-11-12: Link badges follow hello.joekarlsson.io's order, without Letterboxd. hello.joekarlsson.io is an "All my links" button in the badge row, not a separate line.
- 2026-11-12: No still from the homepage hero video of Joe mid-gesture ("very scary").
- 2026-11-12: Intro says "art", not "crop art". Joe lives in Saint Paul.
- 2026-11-12: No photo of Joe that repeats his GitHub avatar (the side-profile shot): it adds nothing next to the avatar.
- 2026-11-12: No dithering or halftone on photos in the README.
- 2026-11-12: Joe likes contribution stats (total, current and longest streak): context on his code and how prolific he is belongs here.
- 2026-11-12: Stats card uses the "When I commit" hour strip (Joe's favorite), not a language bar.
- 2026-11-12: Yes to an animated header (crayon scribbles drawing in) and a homelab card. Link the /uses page or the desk setup post.
- 2026-11-12: No Letterboxd or films: visitors won't care what Joe is watching.
- 2026-11-12: Header scribbles match joekarlsson.com exactly: same paths, one-pen stroke timing, boil filter, crayon line. Don't approximate them.
- 2026-11-12: Newsletter gets its own section (a card linking to the signup page), not a line of text.
- 2026-11-12: The homelab card is a static snapshot: no nightly data job. Its arrow stays (Joe likes it) and must span the gap from the 74 to the node racks.
